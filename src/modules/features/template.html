Hur fungerar vårt system?

Varje del av vår hemsida använder byggblock som gör det enkelt att lägga till, förändra eller fixa problem! Det är bara att uppdatera varje byggblock för sig. med övrig layout enkelt definierat via en JSON fil.

1. Isolerad UI

Tailwind CSS gör det snyggt och snabbt! (template.html)

2. Klienten VS Servern

JavaScript hanterar klienten! (script.js)

3. Enkel API för moduler!

Slutpunkter för dig att enkelt koppla ihop moduler till servern, säkert! (api.ts)
